## Implementation notes

- Each SVG is self-contained: inline PNGs, inline WOFF2 fonts, namespace-safe IDs, CSS/SMIL only, and no runtime network requests.
- Animations start at `0s`; SMIL sequences use explicit `keyTimes`; static-readable values remain present if animation is unsupported.
- Reduced-motion CSS disables CSS motion. SMIL-capable renderers may still apply SMIL; the static frame is intentionally legible without animation.
- The supplied portrait assets are embedded as-is and retain their RGBA alpha; no silhouette mask or face redraw is used.
- Simple Icons glyphs are embedded from the local Simple Icons font subset. Simple Icons identifies the project as CC0. Brand names/logos remain trademarks of their owners.
- Fonts and licenses are included in `fonts/`.

## Verification

The package includes render snapshots at 0s, 2s, 5s, 9s and 13s for each SVG, plus animation-removed and `<img>` checks under `renders/`. The verification report records transparency, clipping, typography/spacing, mobile-width, link and external-request checks.
